Edge Autocomplete

Every keystroke below queries a Spin Function running on WebAssembly at the edge. The suggestion dataset is compiled right into the .wasm module, so a match is answered from memory — no origin round-trip and no cold start. When a term isn't in the edge dataset, the Function transparently forwards to the origin instead.

Input is debounced by 120 ms, and there's no minimum length — even a single character fires a lookup, so you can watch every request answer in the metrics below.

    Try: bmw audi r8 honda odyssey toyota celica
