Block by Client IP

Welcome, developer! This sample shows how to block clients at the edge by maintaining an IP blocklist in the key-value store. A single Function checks each request's client IP against the list before serving the protected resource.

  1. Check access calls GET /check, which compares your client IP against the blocklist.
  2. Block my IP adds your current IP to the list via POST /admin/blocked-ips.
  3. Check access again — you're now blocked with a 401. Clear blocklist resets it.
