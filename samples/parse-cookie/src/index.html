Cookie Parsing

Welcome, developer! This sample shows how a Function parses the Cookie request header at the edge. Set a demo cookie in your browser, then ask the Function to read it back — the cookies are parsed server-side and returned as JSON.

  1. Click Set demo cookie to store AKAMAI_FUNCTIONS_DEMO in your browser.
  2. Click Parse my cookies to call the /cookies endpoint.
  3. The Function parses your Cookie header and returns every cookie it found.
