Concurrent JSON Aggregation

This Spin Function running on WebAssembly at the edge fans out two outbound requests in parallel to an upstream data API, waits for both with Promise.all, extracts one field from each JSON document, and returns the combined values as a single array — one client request, several origin calls, aggregated at the edge.

API endpoints

GET / — this page (the demo UI)
GET /api/facts — runs the aggregation and returns a joined JSON array of facts
