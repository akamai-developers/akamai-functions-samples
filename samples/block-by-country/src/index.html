Block by Country

This sample blocks visitors whose country is on a blocklist. A single Function resolves the client IP to a country and checks it against a list kept in the key-value store.

  1. Your client IP (from true-client-ip) is resolved to a country via ip-api.com.
  2. If that country is on the blocklist, /check responds with 403.
  3. Use the admin controls to add your own country or clear the list.

Note: this demo relies on ip-api.com, which does not resolve the loopback address 127.0.0.1. It works once deployed behind a real client IP.
