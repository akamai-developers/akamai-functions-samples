Cookie-based A/B Testing

Welcome, developer! This sample shows how to run A/B testing at the edge using a routing cookie. A single Function transparently routes each visitor to one of two origins — and keeps them there for the rest of their session.

  1. Your first request has no routing cookie, so it is served from origin-a.
  2. The Function sets the akamai-functions-routing-cookie on the response.
  3. Every subsequent request within the next hour is served from origin-b.
